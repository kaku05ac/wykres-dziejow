# Wykres dziejów świata

Interaktywna kołowa chronologia biblijna: od stworzenia świata do 2026 n.e., z datowaniem według katolickich wydań Biblii, filmami do każdej epoki i wersją polską oraz angielską.

Strona jest w pełni statyczna (HTML, CSS, JavaScript, filmy i obrazy) i działa na GitHub Pages bez żadnego serwera.

- `index.html` – strona
- `styles.css` – wygląd
- `data.js` – dane (wydarzenia, postacie, narody, Kościół)
- `i18n.js` – teksty po polsku i angielsku
- `app.js` – działanie wykresu, osi czasu, filmów i czatu
- `images/events/` – filmy (MP4 i WebM) i obrazy do wydarzeń

Czat „Zapytaj o historię” odpowiada tylko po otwarciu strony w claude.ai; poza nim pokazuje się wyłączony, z informacją.
